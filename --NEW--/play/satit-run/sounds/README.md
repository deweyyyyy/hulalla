# 🎵 Satit Run Sounds

เกมจะทำงานได้ปกติแม้ไม่มีไฟล์เสียง แต่ถ้าต้องการเพิ่มเสียง ให้ดาวน์โหลดเสียงฟรีจากแหล่งต่อไปนี้:

## 📥 แหล่งดาวน์โหลดเสียงฟรี

### Freesound.org (ต้องสมัครฟรี - แนะนำ)
- https://freesound.org/

### Zapsplat (ต้องสมัครฟรี)
- https://www.zapsplat.com/

### Pixabay (ดาวน์โหลดได้โดยตรง)
- https://pixabay.com/sound-effects/

## 🎯 ไฟล์เสียงที่ต้องการ

วางไฟล์ `.mp3` ในโฟลเดอร์นี้ ตามชื่อดังนี้:

1. **bg-music.mp3** - เพลงพื้นหลังสนุกๆ แนว upbeat/game music
2. **jump.mp3** - เสียงกระโดด (short, punchy)
3. **collect.mp3** - เสียงเก็บหนังสือ (ding, chime, coin collect)
4. **collision.mp3** - เสียงชน (thud, crash, hit)
5. **gameover.mp3** - เสียง game over (fail sound, sad trombone)

## 💡 เคล็ดลับ

- เลือกเสียงที่สั้นและกระชับ (ไม่เกิน 1-2 วินาทีสำหรับ SFX)
- bg-music ควรเป็นแบบ loop ได้ (seamless loop)
- ขนาดไฟล์ไม่ควรเกิน 500KB-1MB ต่อไฟล์
- ถ้าไม่มีไฟล์เสียง เกมจะทำงานได้ปกติ แต่ไม่มีเสียง
- ผู้เล่นสามารถเปิด/ปิดเสียงได้จากปุ่มมุมบนขวาของหน้าจอ

## 🎮 การใช้งาน

1. ดาวน์โหลดไฟล์เสียงจากแหล่งที่แนะนำ
2. เปลี่ยนชื่อไฟล์ให้ตรงตามรายการข้างบน
3. วางไฟล์ในโฟลเดอร์นี้
4. รีเฟรชหน้าเกม - เสียงจะทำงานอัตโนมัติ!
