# 🎵 Horror Game Sounds

เกมจะทำงานได้ปกติแม้ไม่มีไฟล์เสียง แต่ถ้าต้องการเพิ่มเสียง ให้ดาวน์โหลดเสียงฟรีจากแหล่งต่อไปนี้:

## 📥 แหล่งดาวน์โหลดเสียงฟรี

### Freesound.org (ต้องสมัครฟรี)
- https://freesound.org/

### Zapsplat (ต้องสมัครฟรี)
- https://www.zapsplat.com/

### Pixabay (ดาวน์โหลดได้โดยตรง)
- https://pixabay.com/sound-effects/

## 🎯 ไฟล์เสียงที่ต้องการ

วางไฟล์ `.mp3` ในโฟลเดอร์นี้ ตามชื่อดังนี้:

1. **horror-ambient.mp3** - เพลงพื้นหลังสยองขวัญ (ambient music)
2. **whisper.mp3** - เสียงกระซิบ/ลมพัด
3. **footsteps.mp3** - เสียงเดิน/ฝีเท้า
4. **scream.mp3** - เสียงกรีดร้อง
5. **door.mp3** - เสียงประตูเปิด-ปิด
6. **heartbeat.mp3** - เสียงหัวใจเต้น

## 🔍 คำค้นหาแนะนำ

- "horror ambient music"
- "ghost whisper sound"
- "footsteps wooden floor"
- "female scream horror"
- "creaky door sound"
- "heartbeat slow breathing"

## ⚠️ หมายเหตุ

- ไฟล์ทุกไฟล์ต้องเป็นไฟล์ `.mp3`
- ขนาดไฟล์ไม่ควรเกิน 1-2 MB ต่อไฟล์
- ถ้าไม่มีไฟล์เสียง เกมจะทำงานได้ปกติ แต่ไม่มีเสียง
